---

## 3. 作り方

1. Open-Meteo の過去データAPIから、9都市ぶんの**1時間ごと**の実測値を取得
   （気温・相対湿度・風速・降水量、タイムゾーンは `Asia/Tokyo`、風速の単位は m/s）
2. **お出かけする時間帯（9時〜18時の10時間）だけ**を残す
3. 1日ごとにまとめる
   - `temperature` / `wind_speed` / `humidity` … 10時間の**平均**
   - `rain_probability` … 10時間のうち**1時間あたり 0.1mm 以上の降水があった時間の割合**
     （例：3時間降っていた → 30%）
4. 10時間そろわない日・欠測がある日は**除外**

再取得するときは次のコマンドです（数十秒で終わります）。

```bash
python fetch_weather.py           # data/weather_jp.csv を作る
python fetch_weather.py --force   # すでにあっても作り直す
```

## 5. 注意点

1. **`rain_probability` は予報の降水確率ではありません。**
   過去データには予報値が含まれないため、
   「その時間帯に実際に雨が降っていた時間の割合」で代用しています。
   そのため **0, 10, 20 … 100 の11段階**しかありません。
2. **雪も降水に含まれます。** 冬の札幌・新潟・仙台では、雪の日が高い値になります。
3. **ERA5 は観測点そのものの値ではなく、再解析（計算で補間した格子）の値**です。
   気象庁の観測値とは少しずれることがあります。
4. **正解ラベル（outdoor / indoor / relax）はこのCSVには入っていません。**
   ラベルは `train_model.py` の中で、天気から「おすすめ度」を計算して付けています
   （作り方は [doc/README.md](README.md) の第4章）。
5. **9都市・6年ぶんの日本の気候**に限られます。海外や離島の一部は対象外です。
