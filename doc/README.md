## 1. ひとことで言うと

**「その日の天気4つから、おでかけ先のタイプを3つのうち1つに当てるモデル」** です。

| 項目 | 内容 |
| --- | --- |
| 種類 | 教師あり学習 / **3クラス分類** |
| アルゴリズム | **勾配ブースティング木**（scikit-learn `HistGradientBoostingClassifier`） |
| 入力 | 気温・降水確率・風速・湿度 の4つの数値 |
| 出力 | `outdoor` / `indoor` / `relax` のどれか1つ＋それぞれの確率 |
| 学習データ | 日本9都市・6年ぶんの**実測**気象データ 19,728日 |
| 成績 | 正解率 **0.817**（理論上の上限 0.822 / 何もしないと 0.388） |
| ファイル | `model/outing_model.pkl`（約 640 KB） |
| 使われる場所 | [app.py](../app.py) の `predict_category()` |

アプリの中では、こう呼ばれています。

```python
model = joblib.load("model/outing_model.pkl")

input_df = pd.DataFrame(
    [[temperature, rain_probability, wind_speed, humidity]],
    columns=["temperature", "rain_probability", "wind_speed", "humidity"],
)
label = model.predict(input_df)[0]        # 'outdoor' / 'indoor' / 'relax'
```

## 2. 入力と出力

### 入力（特徴量）4つ

**列の順番は必ずこの通り**にしてください。順番が違うと、まったく別の予測になります。

| # | 列名 | 意味 | 単位 | アプリで入力できる範囲 | 学習データにあった範囲 |
| --- | --- | --- | --- | --- | --- |
| 1 | `temperature` | 気温 | ℃ | -10 〜 40 | -13.6 〜 36.6（平均 17.9） |
| 2 | `rain_probability` | 降水確率 | % | 0 〜 100 | 0 〜 100（平均 26.0） |
| 3 | `wind_speed` | 風速 | m/s | 0 〜 20 | 0.4 〜 22.4（平均 4.0） |
| 4 | `humidity` | 湿度 | % | 0 〜 100 | 20 〜 100（平均 66.8） |

前処理（標準化など）は**していません**。決定木の仲間は値の大きさをそろえなくても
うまく学習できるため、生の数値をそのまま入れています。

### 出力（3カテゴリ）

| ラベル | 表示名 | どんな日に出るか | おすすめスポット例 |
| --- | --- | --- | --- |
| `outdoor` | 屋外観光 | 雨が少なく、22℃前後で過ごしやすい日 | 公園、神社、海辺、動物園 |
| `indoor` | 屋内観光 | 雨の日、風が強い日 | 水族館、美術館、博物館、映画館 |
| `relax` | リラックス | 蒸し暑い日、寒い日、真夏日 | カフェ、温泉、図書館、スパ |

`predict()` はラベル1つを返しますが、`predict_proba()` を使えば
3カテゴリそれぞれの確率も取り出せます（並び順は `indoor, outdoor, relax`）。

## 3. 学習データ

| 項目 | 内容 |
| --- | --- |
| 出典 | [Open-Meteo Historical Weather API](https://open-meteo.com/)（ERA5 再解析データ） |
| ライセンス | CC BY 4.0（非商用利用は無料・APIキー不要） |
| 都市 | 札幌・仙台・新潟・東京・名古屋・大阪・高知・福岡・那覇 の9都市 |
| 期間 | 2019-01-01 〜 2024-12-31（6年） |
| 件数 | **19,728 行**（1行＝1都市の1日） |
| ファイル | `data/weather_jp.csv`（約 630 KB） |

1時間ごとの実測値のうち、**お出かけする時間帯（9時〜18時の10時間）だけ**を取り出して、
1日1行にまとめています。

- `temperature` / `wind_speed` / `humidity` … 10時間の**平均**
- `rain_probability` … 10時間のうち**雨が降っていた時間の割合**（例：3時間なら 30%）

> ⚠️ 過去データには「降水確率」という項目がありません（予報にしか無い値のため）。
> そこで「実際に雨が降っていた時間の割合」を降水確率のかわりとして使っています。
> そのため 0, 10, 20 … 100 の11段階になります。また、雪も降水に含まれます。

くわしくは [doc/dataset.md](dataset.md) を見てください。

## 4. 正解ラベルの作り方（弱教師あり学習）

気象データには「その日どこへ行くべきか」という**正解は入っていません**。
そこで、天気から3カテゴリの「おすすめ度」を計算するルールを決めて、
それを正解ラベルのかわりにしています。これを**弱教師あり学習**と呼びます。

### おすすめ度の式

```text
体感温度   = 気温 - 1.5 × √風速
不快指数   = 0.81×気温 + 0.01×湿度×(0.99×気温 - 14.3) + 46.3

outdoor = 3.6 × exp(-(気温-22)² / (2×8.5²))     ← 22℃ が頂点の山なり
          - 0.048×降水確率 - 0.200×風速 - 0.020×max(0, 湿度-70)

indoor  = 0.35 + 0.040×降水確率 + 0.220×max(0, 風速-4)

relax   = 0.80 + 0.050×max(0, 湿度-72) + 0.150×max(0, 13-体感温度)
          + 0.160×max(0, 気温-27) + 0.025×max(0, 不快指数-76) - 0.008×降水確率
```

### なぜ「抽選」するのか

このルールをそのまま正解にすると、正解が1つに決まってしまい、
モデルは**ルールを丸暗記するだけ**になります（正解率がほぼ 100% になり、意味がない）。

そこで、おすすめ度をソフトマックス（`温度 = 0.6`）で確率に直してから、
その確率にしたがってラベルを**抽選**しています。
こうすると「屋外でも屋内でもよさそうな日」がまざり、
実際の予測に近い、歯ごたえのある問題になります。

### できあがったラベルの内訳

| ラベル | 件数 | 割合 |
| --- | --- | --- |
| `indoor` | 7,651 | 38.8% |
| `outdoor` | 6,525 | 33.1% |
| `relax` | 5,552 | 28.1% |

### 理論上の上限（ベイズ限界）＝ 0.826

ラベルを抽選で決めているので、**どんなに賢いモデルでも全問正解はできません**。
「毎回いちばん確率の高いカテゴリを答える」のが最善で、その平均正解率が **0.826** です。
これがこの問題の**満点**にあたります。以降の成績は、この数字と比べて読んでください。

## 5. モデルの選び方

候補5つを、学習用データの**5分割交差検証**で比べ、
**マクロF1**（3カテゴリを平等に見た成績）がいちばん高いものを選びました。

| 順位 | モデル | 正解率 | マクロF1 | ばらつき | 対数損失 |
| --- | --- | --- | --- | --- | --- |
| 🥇 | **勾配ブースティング** | **0.821** | **0.815** | ±0.006 | **0.467** |
| 2 | ランダムフォレスト | 0.819 | 0.813 | ±0.006 | 0.487 |
| 3 | 決定木（深さ6） | 0.813 | 0.807 | ±0.008 | 0.520 |
| 4 | ロジスティック回帰 | 0.788 | 0.779 | ±0.006 | 0.601 |
| – | ベースライン（いちばん多いカテゴリを答えるだけ） | 0.388 | 0.186 | ±0.000 | 1.090 |

読み取れること。

- ベースラインの 0.388 → 0.821 なので、**機械学習がちゃんと効いています**
- 直線で区切るロジスティック回帰は一歩およばず、**曲がった境界を引ける木の仲間が強い**
- 1位と2位の差はごくわずか（マクロF1で 0.002）。
  ランダムフォレストでもほぼ同じ性能ですが、**対数損失＝確率の当てかたが良い**ので
  勾配ブースティングを選びました

### 選ばれたモデルの設定

```python
HistGradientBoostingClassifier(
    max_iter=300,           # 木を最大300本つくる
    learning_rate=0.08,     # 1本あたりの学習の強さ
    max_leaf_nodes=31,      # 木1本の細かさ
    l2_regularization=1.0,  # 複雑になりすぎないようにする
    random_state=42,        # 毎回同じ結果にする
)
```

配布する `outing_model.pkl` は、成績を確かめたあとに
**全データ（19,728件）で学習し直した**ものです。

## 6. 成績

学習にいっさい使っていない**評価用データ 3,946 件**での結果です。

| 指標 | 結果 | 満点（ベイズ限界） | ベースライン |
| --- | --- | --- | --- |
| 正解率 | **0.817** | 0.822 | 0.388 |
| マクロF1 | **0.810** | – | 0.186 |
| 対数損失 | **0.477** | – | 1.090 |

**満点 0.822 に対して 0.817**。つまり、この問題で**取れる分はほぼ取り切っています**。
残りの誤差は、モデルの不出来ではなく「どちらとも言える日」がある以上、
どうやっても消せないぶんです。

### 混同行列（縦：正解 ／ 横：予測）

| | indoor | outdoor | relax |
| --- | --- | --- | --- |
| **indoor** | **1296** | 83 | 151 |
| **outdoor** | 54 | **1132** | 119 |
| **relax** | 147 | 167 | **797** |

### カテゴリごとの成績

| ラベル | 適合率 | 再現率 | F1 | 件数 |
| --- | --- | --- | --- | --- |
| `indoor` | 0.866 | 0.847 | 0.856 | 1,530 |
| `outdoor` | 0.819 | 0.867 | 0.843 | 1,305 |
| `relax` | 0.747 | 0.717 | 0.732 | 1,111 |

`relax` がいちばん苦手です。これは、
**リラックス向きの日が「屋外にも屋内にも寄せられる中間の日」と重なりやすい**ためで、
ラベルの作り方から見て自然な結果です（`indoor` との取り違えが 147+151 件）。

### どの入力が効いているか（並べ替え重要度）

その列の値だけをシャッフルして、成績がどれだけ落ちるかを測ったものです。

| 入力 | 重要度 | ひとこと |
| --- | --- | --- |
| `rain_probability` | **0.321** ±0.006 | 雨かどうかが最大の決め手 |
| `temperature` | **0.227** ±0.005 | 次に効く。快適か・暑いか・寒いか |
| `wind_speed` | 0.029 ±0.003 | 効くが小さめ |
| `humidity` | 0.007 ±0.002 | ほとんど効いていない |

湿度が効いていないのは、**湿度が気温や降水と強く連動していて、
気温と降水確率を見れば足りてしまう**ためです。
入力欄から外しても成績はほぼ変わりませんが、
「蒸し暑さ」を画面上で説明するのに使えるので残しています。

## 8. 限界・注意点

**このモデルは授業用の学習教材です。実際の外出の可否判断には使わないでください。**

1. **正解ラベルは人が付けたものではありません。**
   「おすすめ度モデル」というルールから作った疑似ラベルです。
   人の好み（子ども連れ、季節のイベント、混雑など）は入っていません。
2. **降水確率は本物の予報値ではありません。**
   「その時間帯に雨が降っていた時間の割合」で代用しています（0〜100 の11段階、雪も含む）。
3. **学習した範囲の外は苦手です。**
   気温 36.6℃ より上（アプリでは 40℃ まで入力できる）と、
   湿度 20% より下は学習データにありません。予測は出ますが、根拠は薄くなります。
4. **日本の9都市・6年ぶんの気候にしか合わせていません。**
   海外や、9都市から大きく外れた気候の場所は想定外です。
5. **季節・時刻・場所そのものは入力に入っていません。**
   同じ天気なら、沖縄でも北海道でも、1月でも8月でも同じ答えを返します。
6. **`relax` の取りこぼしが約 28% あります**（再現率 0.717）。
   ゆっくり過ごすべき日を、屋内観光や屋外観光としてすすめてしまうことがあります。

## 9. 作り直す手順

```bash
pip install -r requirements.txt
python fetch_weather.py    # data/weather_jp.csv を作る（初回のみ・数十秒）
python train_model.py      # 学習して model/ に保存する
```

乱数の種を 42 に固定しているので、**同じデータなら何度実行しても同じ結果**になります。
`train_model.py` はデータが無ければ自動でダウンロードするので、
`python train_model.py` だけでも動きます。
